# 클릭형 매뉴얼 영상 제작 방식 및 프로그램 접목 기준

## 1. 제작 방향

본 방식은 단순 매뉴얼 영상을 제작하는 데서 끝나지 않고, 영상과 웹 이용가이드를 하나의 안내 시스템처럼 연동하는 것을 목표로 한다. 사용자는 영상을 처음부터 볼 수 있고, 필요한 단계만 클릭해 해당 구간으로 바로 이동할 수 있다. 영상으로 이해가 부족한 경우에는 상세보기를 펼쳐 이미지, 입력 예시, 체크리스트를 함께 확인한다.

공공기관 서비스 특성을 고려해 전체 화면은 차분하고 명확하게 구성한다. 과도한 장식보다는 실제 이용 흐름, 버튼 위치, 입력 순서, 확인 절차가 잘 보이도록 한다.

## 2. 적용 구조

| 구분 | 역할 | 제공 형식 |
| --- | --- | --- |
| 매뉴얼 영상 | 실제 이용 흐름을 30초~2분 단위로 안내 | MP4 |
| 영상 원본 | 수정 가능한 모션그래픽 프로젝트 | Remotion 소스 |
| 음성 | 한국어 여성 내레이션 | MP3 또는 WAV |
| 배경음악 | 안내 음성을 방해하지 않는 저음량 BGM | MP3 또는 WAV |
| 클릭형 HTML | 영상, 단계 버튼, 상세보기 안내를 연결 | HTML/CSS/JS |
| 메뉴 데이터 | 프로그램에서 불러올 수 있는 안내 정보 | JSON |
| 캐릭터/로고 | 기관 톤앤매너 적용 자산 | PNG/GIF/SVG |

## 3. 영상 제작 기준

1. 실제 안내서와 사이트 구조를 기준으로 메뉴별 핵심 흐름을 먼저 정리한다.
2. 메뉴별 원고를 작성하고, 내레이션 길이에 맞춰 타임코드를 확정한다.
3. Remotion 기반으로 화면, 마우스 이동, 클릭 링, 스크롤, 강조 박스, 캐릭터 모션을 제작한다.
4. 마우스 커서는 실제 사용자 조작처럼 클릭 전 잠깐 멈추고, 이동 후 클릭 반응이 보이도록 구성한다.
5. 강조 박스는 텍스트 설명을 과하게 넣지 않고, 실제 입력칸이나 버튼 위치에 맞춰 반투명 박스로 표시한다.
6. 캐릭터는 공식 형태를 유지하되 메뉴 성격에 맞는 자세 이미지를 사용한다.
7. KERIS 및 교육부 로고는 영상과 HTML 화면에서 모두 확인 가능하도록 배치한다.

## 4. 프로그램 접목 방식

개발 중인 프로그램에는 영상 파일만 삽입하는 방식이 아니라, 아래 구조로 메뉴 데이터와 영상 타임코드를 함께 연결하는 것이 좋다.

```json
{
  "id": 1,
  "title": "회원가입·자녀등록",
  "phase": "접수 전",
  "video": "assets/manuals/01_signup.mp4",
  "poster": "assets/manuals/01_signup.png",
  "steps": [
    { "label": "포털 접속", "time": 2 },
    { "label": "본인인증", "time": 7 },
    { "label": "자녀입력", "time": 15 }
  ],
  "details": {
    "fields": [
      ["유아명", "홍길동"],
      ["생년월일", "2021.05.14"],
      ["모집연령", "만 5세"]
    ],
    "checklist": [
      "본인인증 후 회원정보 입력",
      "내자녀관리에서 자녀 정보 저장",
      "로그인과 저장 완료 상태 확인"
    ]
  }
}
```

프로그램에서는 `steps.time` 값을 기준으로 영상의 `currentTime`을 이동시키면 된다. 단계 버튼, 상세보기 버튼, 진행바 클릭은 모두 같은 타임코드 데이터를 바라보게 구성한다.

## 5. 화면 구성 기준

- 첫 화면에는 기관 로고, 안내 제목, 검색/필터, 대표 영상 영역을 배치한다.
- 영상 하단에는 단계 이동 버튼, 처음부터 보기, 재생 버튼, 진행바, 시간 표시를 제공한다.
- 모바일에서는 버튼이 영상 위를 가리지 않도록 영상 아래 조작 영역으로 분리한다.
- 상세보기는 기본 접힘 상태로 두고, 필요한 사용자만 펼쳐서 확인하게 한다.
- 6개 메뉴 카드는 각기 다른 색감과 캐릭터 자세로 구분한다.
- 제작 예정 메뉴도 카드와 단계 구조를 먼저 보여주어 전체 시스템 확장성을 이해할 수 있게 한다.

## 6. 납품 및 개발사 전달 기준

최종 납품 시 사이트 개발자가 바로 붙여 쓸 수 있도록 아래 항목을 함께 제공한다.

| 항목 | 내용 |
| --- | --- |
| HTML 샘플 | 반응형 클릭형 이용가이드 화면 |
| JSON 데이터 | 메뉴명, 요약, 단계명, 타임코드, 체크리스트 |
| MP4 영상 | 메뉴별 최종 영상 |
| 포스터 이미지 | 영상 썸네일 PNG |
| 음성 원고 | 편별 내레이션 스크립트 |
| 음성 원본 | 내레이션 MP3/WAV |
| BGM 원본 | 배경음악 MP3/WAV |
| Remotion 원본 | 추후 수정 가능한 영상 프로젝트 |
| QR 이미지 | 담당자 검토 및 현장 공유용 |

## 7. 견적서 삽입 문구

추후 HTML 형식으로 이용가이드를 사이트에 붙일 경우, 영상 제작 방향과 동일한 톤앤매너 및 구성 방식으로 진행해야 하므로 사이트 개발자가 바로 적용할 수 있는 HTML 파일과 영상 원본 파일을 함께 제공한다.

클릭형 HTML 이용가이드 옵션은 당사에서도 본격 실용화 초기 단계의 제안형 옵션이므로, 별도 개발비가 아닌 추가 작업비 1,000,000원만 견적에 반영했다. 해당 옵션을 진행하지 않을 경우 견적에서 제외 가능하다.

## 8. 검수 체크리스트

- 영상과 보이스 타이밍이 같은 단계에서 일치하는가
- 마우스 이동, 클릭, 스크롤이 실제 사용 흐름처럼 보이는가
- 강조 박스가 실제 버튼과 입력칸 위치에 맞는가
- 모바일에서 버튼과 텍스트가 잘리지 않는가
- 기관 로고와 교육부 표기가 명확히 보이는가
- 영상만 보고 이해가 어려운 사용자가 상세보기에서 바로 확인할 수 있는가
- 개발사가 JSON, MP4, HTML만 연결해도 기능 구현이 가능한가
